# GAFU — X漫画・画風図鑑 ＆制作スタジオ

**公開ページ**：https://umitsuru.github.io/buzz_report/hikaku15/studio/

Grokbotが集めた実際のX投稿画像を、画風選択のための参考資料として閲覧するサイト。
初期版は10種類の固定ID（`GAFU-01`～`GAFU-10`）を収録。

## ファイル
- `styles.json`：固定ID、元投稿URL、作者、画像一覧、画風参照用の一般化ルール
- `index.html`：画風図鑑と制作スタジオ
- `studio.css`：サイトの見た目
- `app.js`：画風選択、スライド閲覧、検索、Claudeへの指示文生成

## 使い方
1. 画風図鑑で実際の投稿画像を3枚ずつ比較し、気になるものを選ぶ
2. 1枚目～最終枚目までのサムネイルを見て、主な参考画像を決める
3. 「この画風を使う指示をコピー」を押し、`GAFU-08` のような固定IDと画像リンクをコピー
4. 「Claudeに10枚のプロンプトを作らせる」フォームで題材、枚数、比率を設定し、指示文をコピー
5. Claudeは共通設定と**01.md～10.md の各画像専用プロンプト**を作成する。共通設定の最後には必ず画像生成待機指示を入れる
6. 画像生成ボットには**生成開始指示を出すまでは画像を作らせない**

## 役割分担
- Grokbot：`../posts/<日付_投稿ID>/raw.json` と `img/` を収集するのみ
- Claude：収集画像の画風・伸びた要因を分析し、新作プロンプトを作る
- 画像生成ボット：選ばれた画風と、各話の個別プロンプトから画像を生成
- サイト：実際の収集画像を表示し、画風IDと指示文をコピーできるようにする（自動画像生成はしない）

## 10種類の画風候補について
各IDは**具体的な投稿画像への参照ID**。作画技法の確定分類を示すものではありません。タイトルやジャンルは管理用ラベルです。詳細な画風は画像を見たClaude・画像生成ボットが言語化してください。

初期版はGrokbotの収集データに保存済みの10投稿（自分の投稿3件を含む）を参照しています。
サンプルの画像は`../posts/`に保存済みのファイルを相対参照します。画像を複製して`studio/`に置いていません。投稿の作者・元X投稿リンクを常時表示し、固有の人物・漫画のセリフ・独特なコマ構成は流用しないこと。

新規収集の投稿は、下の「収集した全投稿」一覧に自動反映されます（GitHub APIの公開アクセスとGrokbotの保存状態に依存）。固定画風IDとして増やすには`styles.json`に項目を追加する必要があります。

**重要**：このサイトは実際の投稿画像を扱います。元画像の利用権や第三者著作物の扱いに注意してください。生成時は具体的な作品・人物を複製せず、一般的な視覚特徴だけ参照します。
