# 画風カタログ（studio）

**公開ページ**：https://umitsuru.github.io/buzz_report/hikaku15/studio/

## ページの中身
1. **集めた投稿の画風**：グロッキーが集めた全投稿を、「参考投稿」ページと同じ番号（No.）で並べる。カードの「この画風で指示をコピー」で、その投稿を画風の参考にする指示文がコピーできる。Claudeには「画風は No.54 で」と番号で伝えればよい
2. **オリジナル画風（S-01〜S-25）**：S-01〜S-15はClaudeによる既存案、S-16〜S-25はChatGPTによる追加案。`original_styles.json` に画風指定 (`spec`) と見本生成用プロンプト (`sample_prompt`) を保存。S-16〜S-25には画像生成Bot用の生成・GitHub保存指示 (`bot_prompt`) もある。見本画像は `originals/S-01.jpg` のように置く。未生成の場合はサイトに生成待ち表示。

## ファイル
- `index.html`：ページ本体（CSSとJSも中に入っている）
- `styles.json`：初期に選んだ10件の画風ID（GAFU-01〜10）と投稿の対応。カードの右上に GAFU 番号として表示する。投稿案No.1 は GAFU-07 を使っている
- `original_styles.json`：オリジナル画風の定義（id, name, hook, spec, why, image, sample_prompt；新規S-16〜S-25にはuse_cases, bot_promptもある）
- `originals/`：オリジナル画風の見本画像。S-16〜S-25 のJPEGは現時点では未生成。見本画像生成後に保存する
- `originals_bot_instructions.md`：S-16〜S-25の見本10枚を画像生成Botに作らせる実行手順とコピー用プロンプト

## 担当
- ClaudeとChatGPT：画風の仕様・見本プロンプト・Bot用の制作指示を管理する（GitHub接続がある場合のみファイルを直接更新する）
- グロッキー：このフォルダには触らない

元の人物・セリフ・物語・構図はコピーせず、画風の一般的な特徴だけを参考にする。

## オリジナル画風の3種類の指示

- **見本のプロンプトをコピー**：同じ回転寿司の左右比較シーンを、選んだ画風で1枚生成する。
- **画風指定をコピー**：投稿案の人物・セリフ・比率を優先しながら、その画風だけを適用する。
- **Botへの指示をコピー**（S-16〜S-25）：見本を1枚制作し、GitHubへ保存できる場合は `originals/S-XX.jpg` へ登録する。GitHub接続がない場合は成功と誤報しない。
- **S-16〜S-25の見本10枚を作るBot指示をコピー**：新規10種類の見本制作を順番に依頼する。内容は `originals_bot_instructions.md` にも記載。

各画風はビジュアルの差別化を狙う提案であり、実際のXでのバズを保証するものではありません。
