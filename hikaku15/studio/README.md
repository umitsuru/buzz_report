# 画風カタログ（studio）

**公開ページ**：https://umitsuru.github.io/buzz_report/hikaku15/studio/

## ページの中身
1. **集めた投稿の画風**：Grokbotが収集したX投稿を参考番号（No.）とともに表示。参考投稿の具体的な人物・セリフ・構図を複製せず、一般的な画風の参考にする。
2. **オリジナル画風（14種）**：2026/11/22にS-05・06・07・08・11・16・18・19・20・22・25を削除（番号は付け直さない）。絵柄、画材、媒体、見せ方を異ならせた独自の25種類。

## ファイル
- `index.html`：画風ギャラリーのページと表示用JavaScript。
- `styles.json`：GAFU-01〜GAFU-10と、参考X投稿の対応。
- `original_styles.json`：オリジナル画風の設定（`id`, `name`, `hook`, `spec`, `why`, `image`, `sample_prompt`。S-16〜S-25は`use_cases`もある）。
- `originals/`：完成した画風見本画像の保存場所。S-16〜S-25のJPEGは未生成なら「見本画像は生成待ち」と表示する。

## サイトでコピーできるプロンプト
- **見本のプロンプトをコピー**：残っている各画風で、共通の回転寿司シーンを1枚生成する。
- **画風指定をコピー**：選んだ画風だけを他の漫画プロンプトに適用する。

**ChatGPT Botによる10枚の一括制作・GitHub保存の指示文はサイト上に掲載しない**。依頼したチャットにのみ提示する。

## 担当
- ClaudeとChatGPT：画風仕様、見本プロンプト、制作指示の管理。
- Grokbot：このフォルダには触らない。

元作品の人物・セリフ・物語・具体的な構図はコピーせず、画風の一般的な特徴を参照する。
