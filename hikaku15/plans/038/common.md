# 共通設定：実家に帰った妻から「カメラ、知らない女がいる」とLINEが来た

あなたは、X向けに「LINEのやりとりの画面」風の画像を15枚作るデザイナーです。

【作品タイトル】実家に帰った妻から「カメラ、知らない女がいる」とLINEが来た

【コンセプト】
妻のみきは週末、実家に帰っている。土曜の昼、夫が家に女を呼ぶと、みきから「カメラ、知らない女がいる」とLINEが来る。猫のこむぎを見守るペットカメラに、夫のパーカーを着た女と、膝で寝るこむぎが映っていた。夫は「テレビ」「姉ちゃん」「家事代行」と言い訳を重ね、女をクローゼットに隠すが、カメラには音も入り、こちらから話すこともできた。みきがスピーカーで「はじめまして、妻です」と挨拶して終わる。
・これは架空の創作です。登場人物はすべて成人で、実在の人物・店・ホテルとは関係ありません
・下品さは文字だけで出す。写真やスタンプに性的な絵は入れない

【画像の仕様（15枚共通）：本物のLINEのトーク画面にできるだけ近づける】
・横長3:2の画像。1回の生成で1ページだけ作る（15枚を1枚にまとめない）
・スマホのLINEのトーク画面の一部を、横長に切り抜いたスクリーンショットのような画像。スマホの外枠、ステータスバー（時計や電池）、入力欄、キーボードは描かない
・【縮尺（いちばん大事）】本物のスマホ（文字サイズ大きめの設定）のLINEのスクリーンショットと同じ縮尺にする。画像の横幅＝縦向きのスマホ1台の画面の横幅。3:2の横長の画像は、縦長のスマホ画面の一部分を切り取ったもの。文字はかなり大きく、吹き出しは画面の横幅の半分以上に広がる
　・数値はすべて「画像の横幅」に対する割合。（　）は横幅1536pxのとき
　・吹き出しの文字1文字の幅（全角）：横幅の約4.8％（約74px）。文字の高さもほぼ同じ。1行は最大12文字で、13文字目からは次の行に折り返す（2行目は1行目の下に、行の間を少しあけて）
　・吹き出しの幅＝左右の余白の合計（約6％・約95px）＋文字数×約4.8％。例：3文字＝約20％（約320px）、5文字＝約30％（約460px）、8文字＝約44％（約680px）、12文字（＝1行いっぱい）＝約64％（約980px）
　・1行の吹き出しの高さ：横幅の約9.5％（約145px）。2行の吹き出しは約14.5％（約225px）
　・相手（左）：画面の左端から約1.5％の位置に、直径約7.5％（約115px）の丸いアイコン。吹き出しの左端は、画面の左端から約11％（約170px）
　・自分（右）：吹き出しの右端は、画面の右端から約2％（約30px）の位置にそろえる
　・【左右の吹き出しが重なる目安】左の吹き出しの右端は「11％＋6％＋文字数×4.8％」、右の吹き出しの左端は「98％−6％−文字数×4.8％」。相手と自分の文字数（1行目）の合計が16文字を超えると、左の吹き出しの右端が右の吹き出しの左端より右に来て、上下に並んだ吹き出しが横方向で重なって見える（例：12文字と12文字なら大きく重なる。8文字と8文字でほぼ接する。5文字と3文字なら真ん中が少しあく）。真ん中に大きな空白ができるのは、どちらも短いときだけ。文字を小さくして真ん中をあけない
　・「既読」と時刻の文字：高さ約2.2％（約34px）の灰色の小さな文字で、吹き出しの外側の下の端（右の吹き出しは左側、左の吹き出しは右側）に置く
　・【吹き出しの上下の間隔】吹き出しどうしの上下の空きはとても狭い。相手と自分が入れ替わるところでも約1.3％（約20px）、同じ人が続けて送ったときは約0.8％（約12px）。上下に間延びした空白を作らない
・これは俺（夫）のスマホの画面。トーク相手は、週末に実家へ帰っている妻で、LINEの登録名は「みき」。画面の右側の吹き出し＝俺（自分）、左側の吹き出し＝みき（相手）
・背景：LINEの標準のトーク画面と同じ、くすんだ水色（#8CABD8）の無地。模様やキャラクターは入れない
・右の吹き出し（俺＝自分）：LINEと同じ明るい緑（#8DE055）の角丸の吹き出しで、右上に小さなしっぽ。文字は黒。吹き出しの左下に、小さな白っぽい文字で「既読」、その下に時刻（例：13:02）
・左の吹き出し（みき＝相手）：白い角丸の吹き出しで、左上に小さなしっぽ。文字は黒。吹き出しの左に、小さな丸いプロフィールアイコン（顔の見えない、青空の風景写真のアイコン）。吹き出しの右下に、小さな白っぽい文字で時刻。1対1のトークなので、吹き出しの上に名前は出さない
・同じ人が続けて送ったときは、2つ目以降の吹き出しにはアイコンを付けない（LINEと同じ）
・文字：LINEと同じような、すっきりしたゴシック体。上の【縮尺】どおりの大きな文字
・通話の履歴：LINEと同じ、吹き出しの形の中に受話器のアイコンと「応答なし」または「不在着信」、その横に通話の時刻。かけた側の色の吹き出しにする（俺がかけた＝右の緑、みきがかけた＝左の白）
・システムのお知らせ（送信取消など）：画面の中央に、半透明の濃い灰色の角丸の帯に白い小さな文字
・写真：角丸の四角で、トークの中に送られた写真として表示する（右なら俺が送った写真）
・日付の帯：LINEと同じく、日付が変わるところで画面の中央に、灰色の角丸の小さな帯で日付を出す（各ページで指定したときだけ）
・アプリのロゴ、実在の店名・ホテル名・会社名は描かない
・各ページは指定された吹き出しだけ。指定のない吹き出しや文字は足さない
・1ページの吹き出しは上から下へ、指定の順番に並べる

【トリミング（この投稿案だけ。画像ごとに比率が変わる）】
・本物のLINEのスクショを切り抜いたように、メッセージ以外の余計な余白がない画像にする。比率は画像ごとに違ってよい
・1枚目：上のLINEの帯（「＜」と「みき」）から、最後の吹き出しの下までを残す
・2枚目以降：上の帯は描かない。メッセージのやりとりの部分だけを残す
・手順：まず横長3:2で生成する（上の【縮尺】どおりの大きさで描き、上下の余白は水色の背景だけにする）。生成した画像を、Python（Pillow）で次のように加工してから保存する。上下の余白を切り、メッセージとメッセージの間の空きすぎも、本物のLINEと同じくらいの間隔に詰める。左右は切らない
```python
from PIL import Image
im = Image.open("生成した画像.png").convert("RGB")
w, h = im.size
bg = im.getpixel((5, h // 2))            # 背景の色を左端から取る
def is_bg(y):                             # その行がほぼ背景色だけか
    px = [im.getpixel((x, y)) for x in range(0, w, 4)]
    return sum(sum(abs(a - b) for a, b in zip(p, bg)) > 40 for p in px) < len(px) * 0.01
rows = [is_bg(y) for y in range(h)]
top = rows.index(False)
bot = h - 1 - rows[::-1].index(False)
pad, gap = int(w * 0.02), int(w * 0.014)  # 上下の余白／メッセージ間の空きの上限（本物のLINEと同じ狭さ）
keep = list(range(max(0, top - pad), top))
y = top
while y <= bot:
    if rows[y]:
        e = y
        while e <= bot and rows[e]: e += 1
        keep += list(range(y, y + min(e - y, gap))); y = e
    else:
        keep.append(y); y += 1
keep += list(range(bot + 1, min(h, bot + 1 + pad)))
out = Image.new("RGB", (w, len(keep)))
for i, yy in enumerate(keep):
    out.paste(im.crop((0, yy, w, yy + 1)), (0, i))
out.save("NN.jpg", quality=92)
```
・1枚目は、上のLINEの帯の文字やアイコンがあるので、そのまま帯から残る。帯が切れた場合は、上は切らずに下だけ切る
・各ページの「切り抜き後の比率の目安」と大きくずれた（縦に余白が残りすぎた）ときは、もう一度だけ切り直す

【1枚目だけ】
・画面のいちばん上に、LINEのトーク画面の上の帯（背景と同じ水色の細い帯）。左に「＜」、中央より左寄りに太い黒い文字で相手の名前「みき」だけを出す。右側に、虫めがね・電話・三本線の小さなアイコン。俺（自分）の名前は出さない

【1枚目の見え方（いちばん大事）】
・Xのタイムラインでは、横長の1枚目は真ん中の横幅3分の1（左から約33〜67％）だけが表示される。1枚目の1つ目の吹き出しは、その見える部分に、決めた文字だけが入るように作ってある
・だから1枚目は【縮尺】の数値を必ず守る：1文字＝横幅の約4.8％、左の吹き出しの文字の書き出しは左端から約14％、12文字以内は必ず1行（折り返さない・文字を小さくしない・吹き出しを中央に寄せない）

【文字のルール】
・吹き出し・時刻・既読・通話・お知らせの文字は、指定どおりに1文字も変えずに描く。「笑」や「？」も指定どおり
・時刻はページの中で上から順に進む

【15枚の連続性】
・15枚すべてで、背景、吹き出しの色と形、アイコン、文字の書体を同じにする
・会話は15枚で1つにつながっている。前のページの続きとして作る
