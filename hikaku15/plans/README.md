# 投稿案（plans）

ClaudeとChatGPTが作った、10枚・15枚・20枚などの連作漫画のプロンプト置き場です。閲覧ページ：https://umitsuru.github.io/buzz_report/hikaku15/plans/

## 複数の形式

| 形式 | 中身 | 向いている題材 |
|---|---|---|
| A | 縦長3:4、1ページ3コマ（上：状況→中：出来事→下：オチ） | 職場の裏側、エピソード漫画、心の声のツッコミが多い話 |
| B | 正方形1:1、1枚絵（コマ割りなし）。左右に2組を並べて矢印ラベル | 「〇〇でバレる」系の比較。スシロー版がこの形で伸びた |
| C | 正方形1:1など指定の比率で1枚絵（コマ割りなし）。1ページ1人を主役にする図鑑型 | 「変なおじさん10選」など、別々の人物を10人紹介する企画 |

`index.json` と `project.json` の `format` に A、B または C を書く。依頼に形式の指定がなければ、Claudeが作り始める前に確認する。

## 番号とフォルダ

- 投稿案の番号（No.1, No.2 …）は `index.json` の `no`。フォルダ名はその3桁（No.1 → `001/`）
- 各フォルダの中身
  - `common.md`：全ページ共通の設定（読んだだけでは画像を作らない）
  - `01.md`〜`NN.md`：各ページの完成版プロンプト（各プロジェクトの `image_count` / `pages` と一致）
  - `project.json`：作品情報、画風（GAFU番号）、参考投稿、ページ一覧
  - `images/01.jpg`〜`NN.jpg`：ChatGPTのボットが生成した完成画像（ページ番号と同じ番号）。ページの「生成した画像」に表示され、Postizで予約投稿するときもここから使う

## ChatGPTの画像生成ボットの動き

「投稿案No.Xの a〜b枚目を作って」と言われたら：

1. `https://umitsuru.github.io/buzz_report/hikaku15/plans/index.json` で No.X のフォルダを確認
2. `…/plans/<フォルダ>/common.md` を読む（ここでは画像を作らない）
3. a枚目から b枚目まで、`…/plans/<フォルダ>/NN.md` を1つずつ読み、1ページにつき1枚生成する
4. 画風の参考画像は `project.json` の `style.reference_image`

## 担当

- Claude：投稿案の追加・修正、`index.json` の更新
- ChatGPTの画像生成ボット：`plans/<フォルダ>/images/` に完成画像を保存するだけ。プロンプトや index.json は変更しない
- グロッキー：このフォルダには触らない

## 20枚の上下比較型

- 20枚企画の番号は各ファイルで `1/20`〜`20/20` と記す。サイトのページ切り替えとコピー指示は `pages:20` に対応する。
- 上下の比較型では `format:"上下比較"` を使える。縦横比は個別作品の指定を優先（No.8は正方形1:1）。
- No.8 の No.55 は上下比較の構成だけの参考。画風は No.8 `common.md` の写実寄りの美麗カラー漫画を優先する。
