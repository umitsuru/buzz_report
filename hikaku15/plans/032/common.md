## 2枚目から：続きの画面（トリミングしたスクショ）※1枚目と、最後の新しい相手からのDMのページは除く
- ステータスバー、上のヘッダー（アイコンと名前）、下の入力欄とタブバーは描かない。メッセージのやりとりの部分だけを切り抜いたスクショにする
- 画像のいちばん上の端で、前のページの最後の吹き出しが切れている（吹き出しの下半分くらいだけが見え、上半分と文字の上側は画像の外）。続きの画面だとひと目でわかるようにする。各ページで、どの吹き出しを見切れさせるか指定する
- その下に、そのページのメッセージを、本物のDMと同じせまい間隔で上から詰めて並べる。吹き出しのあいだに大きな空白を作らない
- 手順：まず縦長2:3で生成する（メッセージは上から詰めて描き、その下の余白は真っ黒のまま何も描かない）。生成した画像を、Python（Pillow）で次のように加工してから保存する。上は切らない。下の黒い余白を切り取り、吹き出しのあいだの空きすぎも詰める。左右は切らない
```python
from PIL import Image
im = Image.open("生成した画像.png").convert("RGB")
w, h = im.size
def is_bg(y):                             # その行がほぼ真っ黒か
    px = [im.getpixel((x, y)) for x in range(0, w, 4)]
    return sum(sum(px_) > 60 for px_ in px) < len(px) * 0.01
rows = [is_bg(y) for y in range(h)]
bot = h - 1 - rows[::-1].index(False)
pad, gap = int(w * 0.04), int(w * 0.03)  # 下の余白／吹き出しのあいだの空きの上限
keep, y = [], 0
while y <= bot:
    if rows[y]:
        e = y
        while e <= bot and rows[e]: e += 1
        keep += list(range(y, y + min(e - y, gap))); y = e
    else:
        keep.append(y); y += 1
keep += list(range(bot + 1, min(h, bot + 1 + pad)))
out = Image.new("RGB", (w, len(keep)))
for i, yy in enumerate(keep):
    out.paste(im.crop((0, yy, w, yy + 1)), (0, i))
out.save("NN.jpg", quality=92)
```
- 切り抜いたあとの比率は、ページごとに違ってよい（縦長〜正方形に近い形）。各ページの「切り抜き後の比率の目安」と大きくずれたら、もう一度だけ切り直す

- 指定以外の文字（署名、英語、ロゴ）は入れない。ステータスバーとヘッダー、入力欄の「メッセージ」は描く
