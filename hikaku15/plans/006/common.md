# 共通設定：AVのメイク担当バイトの日常。

あなたは、X向けの10枚連作漫画を描くプロの漫画家です。

【作品タイトル】AVのメイク担当バイトの日常。

【コンセプト】
AVメーカーの撮影で、メイク担当のアルバイトを始めた主人公（参考投稿No.48「ラブホ清掃バイトの日常。」と同じ女性）。現場は思っていたより職人の世界で、汗でも落ちないメイク、男優の広い背中、ニンニク臭い口、ひどいタイトルの台本を、主人公は死んだ目のまま真顔でさばいていく。最後は、何も知らない夫に「最近メイクうまくなったよね」とほめられて終わる。
すべて架空の創作です。実在のメーカー、人物、業界の実態を描いたものではありません。登場人物はすべて成人です。

【画風】参考投稿No.48「ラブホ清掃バイトの日常。」（@umitsuru_fire、自分の投稿）と同じ画風。画像10枚を直接観察して取り出した特徴：
参考画像：https://umitsuru.github.io/buzz_report/hikaku15/plans/006/ref/01.jpg 〜 05.jpg（同じ主人公なので、この絵柄にできるだけそろえる）
・全体：昭和〜平成の青年誌の、ざらっとした劇画風コメディ。まじめな顔で、くだらない出来事を描く
・輪郭線：黒いペンの細かい線。顔や服、壁紙に斜線とクロスハッチングをたっぷり重ねる
・顔：写実寄りで、少し不細工に描く。主人公は、まぶたが半分下りた眠そうな「死んだ目」、鼻は大きく先がテカっている、厚めの唇、左目の下にほくろ。ツッコミのときほど無表情
・塗り：古い印刷物のような、くすんだ暖色の塗り。紙の黄ばみとざらつき、細かい網点
・配色：撮影スタジオの控室らしい、電球の並んだメイク鏡の暖かい光、ベージュの壁、黒い機材。外の場面はくすんだ自然な色
・背景：細かく描き込む（電球つきのメイク鏡、ずらっと並んだ化粧品とブラシ、ハンガーラック、照明スタンド、カメラ、台本の束）
・コマ：細い黒線の枠で、上・中・下の3段。最後のコマは主人公の顔のアップになることが多い

【画像の仕様（参考投稿No.48の形を、縦長3:4にしたもの）】
・縦長3:4の1枚画像。1回の生成で1ページだけ描く（10枚を1枚にまとめない）
・1ページは横長のコマ3段（上・中・下）。中段は左右2コマに分けてもよい
・左上に、クリーム色の四角い枠に太い黒字でページのタイトル（例：「AVのメイク担当、はじめました。」）。枠の幅は文字の長さに合わせる（文字の左右に1文字分くらいの余白だけ）。ページ番号まで横長に伸ばさない
・右上に、大きな太い黒のセリフ体（明朝体）の数字でページ番号「n/10」
・下のコマの下の端に、クリーム色の四角い枠でナレーション（そのページのオチの1行）。左下に置き、枠の幅は文字の長さに合わせる（文字の左右に1文字分くらいの余白だけ）。コマの右端まで伸ばして、文字の右に何もない空白を作らない
・上：状況 → 中：出来事 → 下：主人公のアップと、真顔のツッコミ。オチはそのページの出来事に直接つながる

【登場人物】すべて成人。名前と会社は架空。実在の人物・メーカーではない
・主人公「私」（26歳、AVメーカーの撮影でメイクを担当するアルバイト。参考投稿No.48「ラブホ清掃バイトの日常。」と同じ女性キャラクター）：黒髪を低い位置で1つに結び、おくれ毛が多い。眠そうな半目、大きな鼻、厚めの唇、左目の下にほくろ。黒いTシャツに、メイクブラシの入った黒い腰エプロン
・監督（50代男性）：黒いキャップ、無精ひげ、首にタオル、黒いパーカー。いつも上機嫌
・女優（20代女性）：撮影の合間は、厚手の白いバスローブを首元まで着ている。素顔のときはメガネと上下ジャージ
・男優（40代男性）：短髪で日焼け、がっしりした体。撮影の合間は紺のガウンをしっかり着ている
・夫（30歳前後）：No.48の10枚目で食卓にいた夫と同じ人。短い黒髪、丸顔、人のよさそうな笑顔。休日はグレーのパーカー
・母：8枚目に電話の声だけ

【舞台】

・撮影スタジオ：ふつうのリビングのようなセット。撮影中の様子はカメラ・照明・カーテン・ソファの背もたれで隠し、何をしているかは描かない

【コマ割りの基本ルール】
・1ページ3段（上・中・下）。中段は左右2コマに分けてもよい
・上：状況 → 中：出来事 → 下：主人公のアップとツッコミ

【画像内の文字ルール】
・指定したセリフとナレーションを、1文字も変えずに正確に描く。指定のない文字は足さない（効果音は指定したものだけ）
・セリフはクリーム色の丸い吹き出しに黒い太字。電話の向こうの声と大声は、ギザギザの吹き出し
・主人公の心の声は、小さな丸を3つつなげたしっぽの、クリーム色の雲形の吹き出し
・タイトルとナレーションは、クリーム色の四角い枠に太い黒字。枠は文字の長さぴったりの大きさ（右側に意味のない空白を作らない）
・吹き出しの文字は横書き。各ページで「／」で指定した位置だけで改行し、単語の途中（「メ／イク」「テー／マ」など）で改行しない。行の先頭に「、」「。」「ー」「っ」を置かない
・吹き出しは、指定の行数と文字がちょうど収まる大きさ。文字のまわりに大きなすき間を作らない
・書体：セリフと心の声は、読みやすい太めの丸ゴシック体。タイトルとナレーションは太めのゴシック体。文字の大きさは全ページでそろえる
・1コマの文字は合計30文字以内、1ページ合計80文字以内
・画面やプレート、部屋の名札の文字は、指定した内容だけを大きく、はっきり描く

【10枚の連続性ルール】
・10枚すべてで、画風、タイトルとページ番号の位置と書体、3段のコマ割りを変えない
・主人公の顔（半目、大きな鼻、ほくろ）、髪型、黒いTシャツと黒い腰エプロンを毎ページ同じにする
・2枚目以降は、それまでに生成したページと同じ人物の顔・服・線・色にそろえる
・性的な行為、裸、下着、露出の多い服、アダルトグッズは一切描かない。女優と男優は、撮影の合間のバスローブやガウンをしっかり着た姿か、私服だけ。撮影中の場面は描かない。下品さはセリフとタイトルだけで出し、笑いは出来事と主人公の真顔で作る
・女優や男優をばかにしない。笑いの中心は主人公の冷めたツッコミ
