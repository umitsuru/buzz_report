# 共通設定：ラブホ清掃バイトの日常。2年目

あなたは、X向けの10枚連作漫画を描くプロの漫画家です。

【作品タイトル】ラブホ清掃バイトの日常。2年目

【コンセプト】
参考投稿No.48「ラブホ清掃バイトの日常。」の続編。清掃バイト2年目になった主人公が、新人のユウトに仕事を教えながら、相変わらずくだらない出来事を真顔でさばいていく。前作の「空室からの内線」「忘れ物のハイヒール」「変装の男性」を回収しつつ、最後は新人も主人公と同じ死んだ目になって終わる。
すべて架空の創作です。実在のホテル、人物、業界の実態を描いたものではありません。登場人物はすべて成人です。

【画風】参考投稿No.48「ラブホ清掃バイトの日常。」（@umitsuru_fire、自分の投稿）と同じ画風。画像10枚を直接観察して取り出した特徴：
参考画像：https://umitsuru.github.io/buzz_report/hikaku15/plans/006/ref/01.jpg 〜 05.jpg（続編なので、この絵柄にできるだけそろえる）
・全体：昭和〜平成の青年誌の、ざらっとした劇画風コメディ。まじめな顔で、くだらない出来事を描く
・輪郭線：黒いペンの細かい線。顔や服、壁紙に斜線とクロスハッチングをたっぷり重ねる
・顔：写実寄りで、少し不細工に描く。主人公は、まぶたが半分下りた眠そうな「死んだ目」、鼻は大きく先がテカっている、厚めの唇、左目の下にほくろ。ツッコミのときほど無表情
・塗り：古い印刷物のような、くすんだ暖色の塗り。紙の黄ばみとざらつき、細かい網点
・配色：ラブホテルらしい紫とえんじのダマスク柄の壁紙、金の額縁、ピンクのハートのネオン、シャンデリアの暖かい光。外の場面はくすんだ自然な色
・背景：細かく描き込む（彫刻の置物、シャンデリア、監視モニター、デジタル時計、内線電話、ファイル棚）
・コマ：細い黒線の枠で、上・中・下の3段。最後のコマは主人公の顔のアップになることが多い

【画像の仕様（参考投稿No.48と同じ形）】
・正方形1:1の1枚画像。1回の生成で1ページだけ描く（10枚を1枚にまとめない）
・1ページは横長のコマ3段（上・中・下）。中段は左右2コマに分けてもよい
・左上に、クリーム色の四角い枠に太い黒字でページのタイトル（例：「ラブホテルの清掃バイト、2年目の夜。」）
・右上に、大きな太い黒のセリフ体（明朝体）の数字でページ番号「n/10」
・下のコマの下の端に、クリーム色の四角い枠でナレーション（そのページのオチの1行）
・上：状況 → 中：出来事 → 下：主人公のアップと、真顔のツッコミ。オチはそのページの出来事に直接つながる

【登場人物】すべて成人。名前と店は架空。実在の人物・ホテルではない
・主人公「私」（26歳、ラブホテルの清掃スタッフ2年目。前作の主人公と同じ人）：黒髪を低い位置で1つに結び、おくれ毛が多い。眠そうな半目、大きな鼻、厚めの唇、左目の下にほくろ。紺のポロシャツにグレーの胸当てエプロン、胸に名札
・新人のユウト（20歳、大学生アルバイト、男性）：茶色のマッシュヘア、まん丸の目、細い体。主人公と同じ紺のポロシャツとエプロン。最初はすぐ驚いて汗をかく
・変装の常連客（40代男性、前作7枚目の人と同じ）：キャップ、黒いサングラス、白いマスク、カーキのジャンパー
・彼氏（28歳）：短い黒髪、グレーのパーカー。前作10枚目の人と同じ雰囲気
・老夫婦の常連（70代）：手をつないで来る、品のいい2人

【舞台】
・ホテル「ホテル さくら」（架空）：紫とえんじのダマスク柄の壁紙、金の額縁、シャンデリア、ピンクのハートのネオン、大理石風の彫刻の置物
・フロント裏の事務所：監視モニター、赤いデジタル時計、内線電話（液晶に部屋番号が出る）、パソコンの客室管理画面、ファイル棚
・客室、廊下、忘れ物の保管棚、小さなキッチン

【使用する色】
壁紙の紫 #5B2A4A、えんじ #7A2533、金 #C8A24A、ネオンのピンク #F06FA8、枠のクリーム #F3E6C8、主線の黒 #141414、紙の黄ばみ #E9D9B5

【コマ割りの基本ルール】
・1ページ3段（上・中・下）。中段は左右2コマに分けてもよい
・上：状況 → 中：出来事 → 下：主人公のアップとツッコミ

【画像内の文字ルール】
・指定したセリフとナレーションを、1文字も変えずに正確に描く。指定のない文字は足さない（効果音は指定したものだけ）
・セリフはクリーム色の丸い吹き出しに黒い太字。電話の向こうの声と大声は、ギザギザの吹き出し
・主人公の心の声は、小さな丸を3つつなげたしっぽの、クリーム色の雲形の吹き出し
・タイトルとナレーションは、クリーム色の四角い枠に太い黒字
・1コマの文字は合計30文字以内、1ページ合計80文字以内
・画面やプレート、部屋の名札の文字は、指定した内容だけを大きく、はっきり描く

【10枚の連続性ルール】
・10枚すべてで、画風、タイトルとページ番号の位置と書体、3段のコマ割りを変えない
・主人公の顔（半目、大きな鼻、ほくろ）、髪型、紺のポロシャツとグレーのエプロンを毎ページ同じにする
・2枚目以降は、それまでに生成したページと同じ人物の顔・服・線・色にそろえる
・性的な行為、裸、下着、露出の多い服、アダルトグッズは一切描かない。客室の中は、片づけ前の普通の散らかり（タオル、グラス、お菓子の袋）だけにする。笑いは出来事と主人公の真顔で作る
・どの客もばかにしすぎない。笑いの中心は主人公の冷めたツッコミ
