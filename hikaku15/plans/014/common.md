# 共通設定：不倫夫の位置情報を、妻が実況した

あなたは、X向けに「LINEのやりとりの画面」風の画像を15枚作るデザイナーです。

【作品タイトル】不倫夫の位置情報を、妻が実況した

【コンセプト】
平日の昼。家族で共有している位置情報アプリで、夫のアイコンがホテル街の同じ建物に2時間止まっている。「会社で会議中」と言い張る夫に、妻は位置情報を見ながら実況し、言い訳を1つずつつぶしていく。最後は、妻が義母を連れてホテルの前に着いたと告げて終わる。
・これは架空の創作です。登場人物はすべて成人で、実在の人物・店・ホテルとは関係ありません
・下品さは文字だけで出す。写真やスタンプに性的な絵は入れない

【参考】参考投稿No.60（浮気男と彼女のLINEのやりとり）の「トーク画面を横長に切り抜いて連作にする」形式だけを参考にする。参考画像の黄色い背景や吹き出しの色、背景のキャラクターはまねしない（色とデザインは下の指定どおり、本物のLINEに合わせる）。元の会話もコピーしない
参考画像：https://umitsuru.github.io/buzz_report/hikaku15/plans/014/ref/01.jpg、https://umitsuru.github.io/buzz_report/hikaku15/plans/014/ref/10.jpg

【画像の仕様（15枚共通）：本物のLINEのトーク画面にできるだけ近づける】
・横長3:2の画像。1回の生成で1ページだけ作る（15枚を1枚にまとめない）
・スマホのLINEのトーク画面の一部を、横長に切り抜いたスクリーンショットのような画像。スマホの外枠、ステータスバー（時計や電池）、入力欄、キーボードは描かない
・【縮尺（いちばん大事）】本物のスマホのLINEのスクリーンショットと同じ縮尺にする。画像の横幅＝スマホの画面の横幅（縦向きのスマホ1台分の幅）として描く。3:2の横長の画像は、縦長のスマホ画面の一部分を切り取ったもの
　・吹き出しの文字の高さ：画像の横幅の約1/40（横幅1536pxなら約38px）。文字を大きくしすぎない
　・1行の吹き出しの高さ：横幅の約1/16。吹き出しの最大の幅：横幅の約70％で、それより長い文は折り返す
　・プロフィールアイコンの直径：横幅の約1/14。「既読」と時刻の文字：吹き出しの文字の半分くらいの大きさ
　・左の吹き出しは画面の左端から約3％、右の吹き出しは右端から約3％の位置にそろえる
　・【吹き出しの間隔（大事）】本物のスマホのLINEと同じく、吹き出しどうしの上下の間隔はかなり狭い。相手の吹き出しと自分の吹き出しが入れ替わるところでも、空きは1行の吹き出しの高さの約1/4（横幅の約1/64、横幅1536pxなら約24px）だけ。同じ人が続けて送ったときはさらに狭く、横幅の約1/100（約15px）。左右の吹き出しのあいだに、間延びした空白の段を作らない。会話がぎゅっと詰まって見えるようにする
　・参考画像（参考投稿No.60）の、画面の幅に対する文字・吹き出し・時刻の大きさの比率に合わせる（色は合わせない）
・これは妻のスマホの画面。トーク相手は夫で、LINEの登録名は「パパ」。画面の右側の吹き出し＝妻（自分）、左側の吹き出し＝パパ（相手）
・背景：LINEの標準のトーク画面と同じ、くすんだ水色（#8CABD8）の無地。模様やキャラクターは入れない
・右の吹き出し（妻＝自分）：LINEと同じ明るい緑（#8DE055）の角丸の吹き出しで、右上に小さなしっぽ。文字は黒。吹き出しの左下に、小さな白っぽい文字で「既読」、その下に時刻（例：13:02）
・左の吹き出し（パパ＝相手）：白い角丸の吹き出しで、左上に小さなしっぽ。文字は黒。吹き出しの左に、小さな丸いプロフィールアイコン（顔の見えない、青空の風景写真のアイコン）。吹き出しの右下に、小さな白っぽい文字で時刻。1対1のトークなので、吹き出しの上に名前は出さない
・同じ人が続けて送ったときは、2つ目以降の吹き出しにはアイコンを付けない（LINEと同じ）
・文字：LINEと同じような、細めのすっきりしたゴシック体。吹き出しの文字ははっきり読める大きさ
・通話の履歴：LINEと同じ、吹き出しの形の中に受話器のアイコンと「応答なし」または「不在着信」、その横に通話の時刻。かけた側の色の吹き出しにする（妻がかけた＝右の緑、パパがかけた＝左の白）
・システムのお知らせ（送信取消など）：画面の中央に、半透明の濃い灰色の角丸の帯に白い小さな文字
・写真：角丸の四角で、トークの中に送られた写真として表示する（右なら妻が送った写真）
・アプリのロゴ、実在の店名・ホテル名・会社名は描かない
・各ページは指定された吹き出しだけ。指定のない吹き出しや文字は足さない
・1ページの吹き出しは上から下へ、指定の順番に並べる

【トリミング（この投稿案だけ。画像ごとに比率が変わる）】
・本物のLINEのスクショを切り抜いたように、メッセージ以外の余計な余白がない画像にする。比率は画像ごとに違ってよい
・1枚目：上のLINEの帯（「＜」と「パパ」）から、最後の吹き出しの下までを残す
・2枚目以降：上の帯は描かない。メッセージのやりとりの部分だけを残す
・手順：まず横長3:2で生成する（上の【縮尺】どおりの大きさで描き、上下の余白は水色の背景だけにする）。生成した画像を、Python（Pillow）で次のように加工してから保存する。上下の余白を切り、メッセージとメッセージの間の空きすぎも、本物のLINEと同じくらいの間隔に詰める。左右は切らない
```python
from PIL import Image
im = Image.open("生成した画像.png").convert("RGB")
w, h = im.size
bg = im.getpixel((5, h // 2))            # 背景の色を左端から取る
def is_bg(y):                             # その行がほぼ背景色だけか
    px = [im.getpixel((x, y)) for x in range(0, w, 4)]
    return sum(sum(abs(a - b) for a, b in zip(p, bg)) > 40 for p in px) < len(px) * 0.01
rows = [is_bg(y) for y in range(h)]
top = rows.index(False)
bot = h - 1 - rows[::-1].index(False)
pad, gap = int(w * 0.02), int(w * 0.014)  # 上下の余白／メッセージ間の空きの上限（本物のLINEと同じ狭さ）
keep = list(range(max(0, top - pad), top))
y = top
while y <= bot:
    if rows[y]:
        e = y
        while e <= bot and rows[e]: e += 1
        keep += list(range(y, y + min(e - y, gap))); y = e
    else:
        keep.append(y); y += 1
keep += list(range(bot + 1, min(h, bot + 1 + pad)))
out = Image.new("RGB", (w, len(keep)))
for i, yy in enumerate(keep):
    out.paste(im.crop((0, yy, w, yy + 1)), (0, i))
out.save("NN.jpg", quality=92)
```
・1枚目は、上のLINEの帯の文字やアイコンがあるので、そのまま帯から残る。帯が切れた場合は、上は切らずに下だけ切る
・各ページの「切り抜き後の比率の目安」と大きくずれた（縦に余白が残りすぎた）ときは、もう一度だけ切り直す

【1枚目だけ】
・画面のいちばん上に、LINEのトーク画面の上の帯（背景と同じ水色の細い帯）。左に「＜」、中央より左寄りに太い黒い文字で相手の名前「パパ」だけを出す。右側に、虫めがね・電話・三本線の小さなアイコン。妻（自分）の名前は出さない

【文字のルール】
・吹き出し・時刻・既読・通話・お知らせの文字は、指定どおりに1文字も変えずに描く。「笑」や「？」も指定どおり
・時刻はページの中で上から順に進む

【15枚の連続性】
・15枚すべてで、背景、吹き出しの色と形、アイコン、文字の書体を同じにする
・会話は15枚で1つにつながっている。前のページの続きとして作る
