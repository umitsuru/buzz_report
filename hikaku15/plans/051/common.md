# 共通設定：コンドーム工場のバイトの日常。

あなたは、X向けの10枚連作漫画を描くプロの漫画家です。

【作品タイトル】コンドーム工場のバイトの日常。

【コンセプト】
コンドーム工場で検査と箱詰めのアルバイトを始めた主人公（投稿案No.6「AVのメイク担当バイトの日常。」、参考投稿No.48「ラブホ清掃バイトの日常。」と同じ女性）。みんなが想像する「社員が試す」「職場はずっと下ネタ」は全部ちがい、試すのは機械、職場はパートのおばちゃんたちの晩ごはんと孫の話ばかり。主人公は死んだ目のまま真顔で現実を知っていく。最後は、教育係の「何も起きないのが一番の成功」という言葉が、自分の家の夜に返ってくる。
元ネタ：テキスト投稿「コンドーム工場バイトの想像と現実」（claude-buzz-text No.275、表示786万）。検査の中身（全数の電気ピンホール検査、破裂試験で18リットル以上）はメーカー公式の説明にもとづく。
すべて架空の創作です。実在のメーカー、人物、工場を描いたものではありません。登場人物はすべて成人です。

【画風】投稿案No.6「AVのメイク担当バイトの日常。」と同じ画風・同じ主人公（参考投稿No.48と同じ）。
参考画像：https://umitsuru.github.io/buzz_report/hikaku15/plans/006/images/01.jpg、https://umitsuru.github.io/buzz_report/hikaku15/plans/006/images/04.jpg、https://umitsuru.github.io/buzz_report/hikaku15/plans/006/images/10.jpg、https://umitsuru.github.io/buzz_report/hikaku15/plans/006/ref/01.jpg（同じ主人公なので、この絵柄にできるだけそろえる）
・全体：昭和〜平成の青年誌の、ざらっとした劇画風コメディ。まじめな顔で、くだらない出来事を描く
・輪郭線：黒いペンの細かい線。顔や服、壁、機械に斜線とクロスハッチングをたっぷり重ねる
・顔：写実寄りで、少し不細工に描く。主人公は、まぶたが半分下りた眠そうな「死んだ目」、鼻は大きく先がテカっている、厚めの唇、左目の下にほくろ。ツッコミのときほど無表情
・塗り：古い印刷物のような、くすんだ色の塗り。紙の黄ばみとざらつき、細かい網点
・配色：工場らしい、白い作業着、ステンレスの銀、蛍光灯の青白い光、薄緑の床。休憩室や家はくすんだ暖色
・背景：細かく描き込む（ステンレスの機械、ベルトコンベア、ずらっと並んだ金属の型、検査用の水槽、段ボール箱、安全標語のない無地の掲示板）
・コマ：細い黒線の枠で、上・中・下の3段。最後のコマは主人公の顔のアップになることが多い

【画像の仕様（参考投稿No.48の形を、縦長3:4にしたもの）】
・縦長3:4の1枚画像。1回の生成で1ページだけ描く（10枚を1枚にまとめない）
・1ページは横長のコマ3段（上・中・下）。中段は左右2コマに分けてもよい
・左上に、クリーム色の四角い枠に太い黒字でページのタイトル（例：「コンドーム工場、はじめました。」）。枠の幅は文字の長さに合わせる（文字の左右に1文字分くらいの余白だけ）。ページ番号まで横長に伸ばさない
・右上に、大きな太い黒のセリフ体（明朝体）の数字でページ番号「n/10」
・下のコマの下の端に、クリーム色の四角い枠でナレーション（そのページのオチの1行）。左下に置き、枠の幅は文字の長さに合わせる（文字の左右に1文字分くらいの余白だけ）。コマの右端まで伸ばして、文字の右に何もない空白を作らない
・上：状況 → 中：出来事 → 下：主人公のアップと、真顔のツッコミ。オチはそのページの出来事に直接つながる

【登場人物】すべて成人。名前と会社は架空。実在の人物・メーカーではない
・主人公「私」（26歳、コンドーム工場で検査と箱詰めをするアルバイト。No.6・No.48と同じ女性キャラクター）：黒髪を低い位置で1つに結び、おくれ毛が多い。眠そうな半目、大きな鼻、厚めの唇、左目の下にほくろ。工場では白い作業着と白い帽子（髪を帽子に入れる）、マスクはあごまで下げて顔が見えるように。私服は黒いTシャツ
・教育係のおばちゃん（60代女性、勤続30年）：白い作業着と帽子、丸メガネ、ふくよかで面倒見がいい。いつもにこにこしているが、仕事の話になると職人の顔
・パートのおばちゃんたち（50〜60代女性、2〜3人）：白い作業着。休憩中はお茶と手作り弁当
・友達（20代女性2人）：私服。6枚目の居酒屋だけ
・夫（30歳前後）：No.6の10枚目の夫と同じ人。短い黒髪、丸顔、人のよさそうな笑顔。家ではグレーのパーカー
・母：8枚目に電話の声だけ

【コマ割りの基本ルール】
・1ページ3段（上・中・下）。中段は左右2コマに分けてもよい
・上：状況 → 中：出来事 → 下：主人公のアップとツッコミ

【画像内の文字ルール】
・指定したセリフとナレーションを、1文字も変えずに正確に描く。指定のない文字は足さない（効果音は指定したものだけ）
・セリフはクリーム色の丸い吹き出しに黒い太字。電話の向こうの声と大声は、ギザギザの吹き出し
・主人公の心の声は、小さな丸を3つつなげたしっぽの、クリーム色の雲形の吹き出し
・タイトルとナレーションは、クリーム色の四角い枠に太い黒字。枠は文字の長さぴったりの大きさ（右側に意味のない空白を作らない）
・吹き出しの文字は横書き。各ページで「／」で指定した位置だけで改行し、単語の途中（「メ／イク」「テー／マ」など）で改行しない。行の先頭に「、」「。」「ー」「っ」を置かない
・吹き出しは、指定の行数と文字がちょうど収まる大きさ。文字のまわりに大きなすき間を作らない
・書体：セリフと心の声は、読みやすい太めの丸ゴシック体。タイトルとナレーションは太めのゴシック体。文字の大きさは全ページでそろえる
・1コマの文字は合計30文字以内、1ページ合計80文字以内
・画面やプレート、部屋の名札の文字は、指定した内容だけを大きく、はっきり描く

・2枚目以降は、それまでに生成したページと同じ人物の顔・服・線・色にそろえる
・性的な行為、裸、下着、露出の多い服、アダルトグッズは一切描かない。製品は個包装・無地の箱・検査機の型にかぶせた膜・ふくらんだ風船としてだけ描く。下品さはセリフとタイトルだけで出し、笑いは出来事と主人公の真顔で作る
・工場の人たちをばかにしない。笑いの中心は主人公の冷めたツッコミと、想像と現実のずれ
