# 共通設定：平成のデリヘル嬢と令和のデリヘル嬢。20の違い

あなたはX向けの比較型スライド投稿を制作するイラスト作家です。以下は全20枚に共通する人物・画風・レイアウト・文字・演出の設定です。

【作品タイトル】
平成のデリヘル嬢と令和のデリヘル嬢。20の違い

【企画の骨子】
2008年（平成20年）と2026年（令和8年）、デリバリーヘルス業界に勤める架空の成人女性それぞれ1人を、各ページの同じテーマで並べる20枚の時代比較漫画。
上段の平成女性と下段の令和女性は別人で、どちらも27歳。髪型、メイク、バッグ、宣材写真、店への連絡、待機、移動、休憩、収入の使い道、将来設計など「働く人としての生活文化の違い」を描く。
コメディとしての誇張・創作表現であり、当時または現在のすべての業界従事者を代表する記録ではない。平成の女性にもプロ意識があり、令和の女性にも迷いや弱さがある。
仕事内容を描くときは受付・移動・ホテルの廊下での挨拶・仕事前後の準備までとし、性的なサービスの行為そのものは描かない。

【最重要：独自画風】
写実にかなり近い、美麗な大人向け青年漫画の完成カラー原稿。写真や3DCGではなく、精緻な漫画の主線と塗りを残したイラスト。
・肌には自然なハイライトと柔らかな陰影、髪には細い毛束、目元には繊細なまつ毛、唇には上品なツヤ。骨格・指・腕・姿勢は自然で美しく、高品質なファッション誌の挿絵のような仕上がり。
・光は上段が2008年のやや暖かい電球光、下段が2026年の透明感のあるニュートラルなLED光。単純な「平成は汚い／令和は清潔」にはせず、両者とも魅力的で清潔。
・髪・衣装・メイク・小物の時代らしさを丁寧に表現。2008年は盛り髪・濃いアイライン・キラキラしたアクセサリー・ガラケー・雑誌文化。2026年は毛束の軽いレイヤー・洗練された艶肌メイク・スマホ・SNS・効率化の文化。
・大人の色気は表情、視線、しぐさ、ファッションの着こなしで表現する。露骨な胸元や下着、裸体、性行為や性的な接触は描かない。
・実在のモデル、AV女優、タレント、漫画家や既存キャラクターには似せない。画像20枚の間でそれぞれの女性の顔の同一性を維持する。
・過度な性的誇張、豪華すぎる背景、広告写真のような完全実写、下手なラフ絵、ちびキャラ、ギャグ顔は避ける。

顔：切れ長の濃い茶色の瞳、鼻筋が通ったやや面長の顔、頬骨に自然な立体感、笑うと右頬に小さなえくぼ。
髪：明るいハニーブラウンの長い巻き髪をボリューム多めに盛る。長めの前髪、髪には細いハイライト。
肌：健康的でやや小麦色。細めの眉、黒の囲みアイライン、色味のあるリップ。
標準衣装：サテンの黒とボルドーを基調にした女性らしいワンピースの上に薄いベージュのジャケット、細いゴールドネックレス、ヒール、少し大きなブランドロゴのないバッグ。露出は控えめで丈と胸元は上品。
性格：愛想がよく、声が大きく、親しみのある接客。紙のメモと電話で仕事を回すのが得意。少し見栄っ張りだが誠実。

【レイアウト：20枚すべて同じ】
・正方形1:1、1ページ1画像で全20枚。
・画像の最上部に白地のタイトル帯約10%、中央に各ページの見出し。右上に黒い角丸・白文字「n/20」。
・タイトル帯の下を上段「平成・2008」、下段「令和・2026」の2つの横長の帯状シーンに分ける。上下の比率は等しく、中央に細い白線。上段を平成、下段を令和で20枚絶対に入れ替えない。
・上段左上に「平成・2008」、下段左上に「令和・2026」の固定ラベル。各段の女性のサイズ・カメラアングル・ポーズをほぼ揃え、違う道具や雰囲気を見せる。
・原則、各段の吹き出しは本人の短いセリフを1つだけ。ページ指定の発言を正確に描く。小物のアプリ画面や広告に勝手な長文を入れない。
・各段の主役は女性本人1人。必要なら職場の同僚や店員の存在を小物・匿名の背景でほのめかしてもよいが、元来の比較の主役は常に女性本人。
・ページ番号、見出し、上下ラベルと台詞はスマホ縮小表示でも読める大きさ。20枚を一括コラージュにしない。

【時代差と物語の温度】
前半の髪形・メイク・写真・持ち物で視覚的な差を強く出す。中盤で「営業・待機・移動・応対」の仕事上の考え方の違い、後半でお金・部屋・恋愛観・将来観を描く。
